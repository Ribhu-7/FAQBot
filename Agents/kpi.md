# FAQBot — KPIs

## Functional Acceptance Criteria

| KPI # | KPI Name | Verification Method | Status |
|---|---|---|---|
| F-1 | Widget Load Time ≤ 2s | Measure load time on standard broadband using browser DevTools | ⬜ Pending |
| F-2 | FAQ Match Accuracy ≥ 90% | Manual testing across all FAQ entries | ⬜ Pending |
| F-3 | Fallback Shown for Out-of-Scope Questions (100%) | Test with clearly unrelated questions | ⬜ Pending |
| F-4 | API Key Not Exposed to Client | Inspect browser network tab and frontend source | ⬜ Pending |
| F-5 | Cross-Browser Compatibility | Manual test on Chrome, Firefox, Safari, iOS, Android | ⬜ Pending |

## Business KPIs (Post-Launch, 30-Day Window)

| KPI # | KPI Name | Verification Method | Status |
|---|---|---|---|
| B-1 | FAQ Deflection Rate ≥ 60% | Analytics: matched sessions / total sessions | ⬜ Pending |
| B-2 | Fallback Rate ≤ 40% | Analytics: fallback sessions / total sessions | ⬜ Pending |
| B-3 | Support Email Volume ↓ 20% (within 60 days) | Compare pre/post-launch email counts | ⬜ Pending |
| B-4 | Widget Engagement Rate ≥ 10% | Analytics: widget opens / unique visitors | ⬜ Pending |
| B-5 | Response Time ≤ 3s (95th percentile) | Server logs / monitoring under normal load | ⬜ Pending |
